# Supervisor 本地验收页面

Vue 3、TypeScript、Vite。生产页面由当前 Spring Boot 服务同源提供，访问 `http://127.0.0.1:8080/`。运行时使用打包后的本地资源，不依赖 CDN。

## 构建

在 frontend 目录执行：

```bash
npm ci --no-audit --no-fund
npm run build
```

`build` 先执行 vue-tsc 类型检查，再生成以下资源，不清空整个静态资源目录：

- `../src/main/resources/static/index.html`
- `../src/main/resources/static/assets/supervisor.js`
- `../src/main/resources/static/assets/supervisor.css`

随后回到项目根目录运行 `mvn -q -DskipTests package`，配置原有认证环境变量，运行 `bash run-supervisor-server.sh`。交付产物已保存在静态资源目录，因此仅构建 Maven 也能打包已生成的页面；修改前端源码后应先重新执行 npm run build。开发使用 `npm run dev`，API 代理到本机 8080。

## 使用

1. 点击“配置令牌”，输入与服务端启动配置匹配的访问令牌。密码输入框掩码，令牌仅在页面内存，不写入任何浏览器存储、日志或静态文件；刷新后重新输入。
2. 输入问题，可选择同步等待完整结果，或异步受理后轮询。普通发送会在当前会话任务运行中禁用；空白或超过 2000 个 UTF-16 单元的输入会被校验拦截。
3. 等待补充时，输入框用于回答当前问题；已知任务号的活动任务可以停止或切换。同步等待尚无任务号时不能停止；关闭页面或中断请求不代表任务被取消。
4. 答复下可展开任务和请求详情，查看会话号、请求号、任务号、版本、模型调用次数、HTTP 状态与耗时；认证头不被记录。
5. 当前标签页的会话恢复标识与未确认请求体存于 sessionStorage，回答和证据正文不持久化。刷新后重新认证，再按任务号获取服务端结果；未知任务号的请求必须主动确认身份并重放同一请求编号。

## 模块

- `src/api.ts`：认证头、请求等待边界、可读错误、隐藏认证信息的请求追踪。
- `src/store.ts`：会话与响应式任务状态、稳定请求号、恢复、串行轮询及迟到响应隔离。
- `src/App.vue`：会话导航、输入、模式、令牌弹窗和任务控制。
- `src/components/MessageCard.vue`、`EvidenceCards.vue`：答复、天气/车票/资料证据及任务详情。
- `src/presentation.ts`：关闭原始 HTML 的 Markdown、链接限制和内部错误信息转换。

## 验证边界

本轮没有编写或运行单元测试，没有新增自动化测试文件。验收使用真实浏览器与live真实模型；天气、车票仍为本地示例数据；分钟预算、并发和证据权限仍由原后端执行，页面不会绕过保护或自动重建任务以追求成功结果。


## v1.2页面入口（2026-11-01）

- 左侧“验收场景43”：按原问题编号搜索、分类，关联当前任务副本，分别记录人工证据与分支。只有具体结论、有效证据、全部分支和人工核对齐备才允许标通过。没有触发的内部机制使用部分验证或阻塞。
- 支持本地JSON与Markdown导出。结论、回答和证据副本仅在内存；刷新或改变认证会清除正文。sessionStorage仅存恢复标识和原提交体。撤权查询返回403/404时同步撤下关联副本和旧结论。
- “显式偏好”：读取、创建、更改、设置有效期与删除出发城市/席别；写入有明确确认。409保留草稿并要求读取最新版本，204按空正文处理。
- 任务运行中支持补充、修改、动作澄清、切换和停止。动作反馈先显示受理信息，再读取实际任务状态。
- 执行过程只显示真实事件顺序；没有完整调用图、逐子任务费用或计划正文时不会推测。任务详情内可以显式重放原编号、同号异参和合法旧版本；初始版本1不能发送版本0。

实际验收见 `../docs/页面验收报告-v1.2.md`。43项包含平台能力缺口，页面入口齐全不代表后台43项全部实现。
