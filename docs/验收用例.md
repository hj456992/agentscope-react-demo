## 验证边界

天气、车票及资料是本地示例数据；离线模型验证运行协议，不能证明真实模型的规划效果。网络模型测试使用本机模拟 HTTP 服务，没有调用外部付费模型、真实天气/票务服务，也没有生产容量压测。AnswerVerifier 保留独立组件测试，核心最终回答不自动调用它，因此不能声称任意模型事实错误都会被自动拦截。

关键新增覆盖：23项生命周期测试、18项上下文测试、4项核心源码行为测试；其余包括真实SDK HTTP分类重试、并发控制、独立JVM断电恢复、幂等账本、服务端历史与接口。XML结果位于 `target/surefire-reports`，重新运行可复现。

第一次全套执行使用 `JAVA_TOOL_OPTIONS`，该环境变量把启动提示注入子JVM输出，导致指纹字符串断言失败。最终命令改用 Maven 自身参数和测试JVM参数，未修改指纹实现或降低断言。实际端口用例移除了旧“意图识别阶段必须返回UNKNOWN_INTENT”断言，改为验证模型直接返回非空回答且没有虚假证据，与新的统一循环一致。

旧版结果存入 archive/v3.3-验收用例.md；打包及运行验证见实施记录。
