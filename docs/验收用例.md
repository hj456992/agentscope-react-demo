## 运行方式与覆盖层次

- `mvn -q clean test`：120 项，退出码 0。
- `mvn -q -Dtest=SupervisorSocketIT test`：5 项，退出码 0；实际启动 Netty 本机随机端口并发出 HTTP 请求。
- 两个崩溃场景使用独立 JVM 与 Runtime.halt：任务检查点恢复、下游已提交而账本未落成功状态的恢复。
- ModelTransportTest 的 429、401、额度不足走本地真实 HTTP 服务和实际 SDK；网络 cause 分类是精确异常链注入，不冒充公网断网验收。
- 前端测试页由服务直接托管：启动后访问 `http://127.0.0.1:8080/`，已实测渲染、预设、发送、证据表与请求日志。
- 未调用外部模型供应商，未连接真实天气/票务系统，未做生产容量压测。
