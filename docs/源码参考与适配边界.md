# 源码参考与适配边界

当前版本：v3.4，2026-10-29。主参考为 `openai/codex` 固定提交 **`360319d8dee62d87e2d59fc0c21805d79519cfed`**（rust-v0.165.0）。本次选择 MultiAgent V2、保留父历史前缀的 fork、普通消息不自动启动闲置会话，以及无远端压缩能力时的 local compact 路径。Java 使用 Chat Completions 模型接口，不宣称覆盖该提交全部 Responses、远端压缩或后台调度分支。

已核对公开 Rust 源码。Claude 公开 SDK 可辅助核实客户端调用与工具验证，不能证明 Claude Code 未公开的核心实现；本轮运行契约不混入 Claude 闭源推断。没有执行 Codex 自身测试。当前 Java 验证记录见[实施记录](实施记录.md)，不能用测试数量代替源码一致性结论。

## 必须保留的适配差异

这些差异是当前一致性边界，不是以旅行场景为理由取消要求，也不能称为“完整移植”。

- **传输协议。** 当前Chat Completions只接收文本/工具调用和完成原因；未实现Responses的`end_turn=false`、opaque compaction item、增量工具声明、模型兼容hash、world-state注解及异步候选安装。固定提交没有旧`compact_remote.rs`，实际远端实现为`compact_remote_v2.rs`及attempt/installation模块；不能把自然语言摘要称remote v2。
- **压缩策略。** 上游local保留用户上限20,000近似token；本项目6656输入字节上限更小，保留数量进一步受系统指令、摘要、工具定义剩余空间约束，边界原文可能截断并标记来源不完整。不是无损压缩。上游重注入context位置与Chat接口首条SYSTEM的表达不同。当前未接入pre/post compact hooks、后台压缩、post-turn阈值及模型切换压缩。
- **错误和调度。** 上游provider重试配置与公共Responses重试状态机未完整搬入；当前最多三次真实尝试、超时与读并发上限是应用配置。完整SDK流/网络取消和远端计算停止是不同问题。当前询问通过HTTP持久挂起恢复，而非上游交互界面；没有接入request_user_input_async。
- **Agent协议。** 当前固定角色模型工厂未暴露上游spawn的model/reasoning_effort覆盖与role优先级。send/followup的成功回执、list的字段与resident-only过滤等仍需逐项核对，不能仅以工具同名宣称完全一致。当前不提供WakeOnAgentMessages、durable sleep、residency卸载/懒加载机制。
- **恢复和关闭。** Java重启扫描并恢复RUNNING子回合；上游V2身份恢复与按需加载不是同一策略。TaskService关闭等待本地订阅归属清理，不能等同外部阻塞服务已经停机。取消后的完整历史跨新HTTP根任务继承仍须独立验证，不能用child followup的中断测试代替。
- **业务保护。** 身份、事务、全局限额、偏好CRUD和SideEffectLedger是Java服务边界。`KnowledgeService`与`AnswerVerifier`作为可独立复用的检索/校验组件保留，核心终答不再自动经过AnswerVerifier。字段Schema、日期格式、资源权限不是自然语言条件忠实性的证明；删除旧关键词门禁后不能宣称后者已被自动验证。

## 16 项能力的当前归属

| # | 能力 | 当前入口与准确边界 |
|---|---|---|
| 1 | 子Agent失败 | 独立回合错误/完成通知、检查点恢复；模型决定收到失败后如何继续 |
| 2 | 执行中新输入 | 有序输入、邮箱、完成版本栅栏；不同来源不合成用户授权 |
| 3 | 时间与次数 | 树共享预留额度、绝对期限；配置值非上游标准或实测容量 |
| 4 | 工具幂等 | ToolExecutor读缓存、SideEffectLedger稳定业务操作号；非通用恰好一次 |
| 5 | 多Agent分工 | 独立session和V2协作；旅行角色只决定提示词/工具集合 |
| 6 | 传递与去重 | task_name/父子关系、调用编号、持久邮箱；消息确认与检查点配合 |
| 7 | 多轮与长期记忆 | ConversationService隔离历史与显式偏好；与运行检查点分别保存 |
| 8 | 召回正确但回答错 | KnowledgeService/AnswerVerifier组件保留；未挂为核心自动终答保证 |
| 9 | 长上下文 | 真实模型摘要、用户保留与截断标记、原子替换、失败保留旧历史 |
| 10 | 单工具失败 | 失败结果回模型、成功证据独立保存；不自动重跑整个任务树 |
| 11 | 重试分类 | ToolExecutor/RunContext；原样重试受错误类别、预算、取消约束 |
| 12 | 外部副作用 | 先持久claim再调用、结果未知查询下游；依赖下游能力 |
| 13 | 参数格式错 | 注册工具Schema与执行校验，错误以原调用ID回模型 |
| 14 | 参数业务含义 | 具体服务字段/支持范围检查；自然语言条件忠实性仍需专门验证 |
| 15 | 不存在工具 | 注册查找失败回模型，有限纠错；不反射执行任意方法 |
| 16 | 无权限工具 | 身份过滤、运行检查、历史/缓存/证据回放重新授权 |

## 阅读顺序

先读 `Supervisor`、`LoopConversation`、`ContextCompactor`，再读 `RunControl`、`LocalAgentControl`、`service/TaskService`、`service/TaskStoreService`，最后读工具、记忆、校验及repo/MyBatis。`TravelAgentFactory.stage`为独立校验组件保留SDK ReActAgent入口；主子Agent的运行路径均是Supervisor显式循环，不能据此误称子生命周期仍由SDK隐式管理。
