## 原包逐类处理

| 原文件 | 处理 |
|---|---|
| Supervisor | 重写，保留三阶段；增加检查点和输入边界；最终统一校验 |
| RunContext | 重写，共享持久预算、稳定步骤号、成功证据、终止状态 |
| ChildAgentDispatcher | 重写，可信参数、完成结果回放、降权校验、错误分类 |
| TravelAgentFactory | 修改，注册可见工具、Schema 中间件、关闭隐藏重试 |
| TravelTools | 修改，有界异步读取、条件校验、失败分类、去重 |
| QueryRewriter | 修改，使用新上下文装配，保留原文条件 |
| IntentRecognizer | 复核结构校验，业务校验拆到 BusinessConditions；格式整理 |
| OfflineScenarioModel | 修改，增加资料检索和答案引用脚本；仍不是通用模型 |
| SupervisorContracts | 修改，新增 requestId 和明确运行终态，兼容原构造方式 |
| SupervisorController | 重写为六个认证接口 |
| SupervisorConfiguration | 修改，装配数据库、任务、权限、传输与核对器 |
| SupervisorSettings | 修改，集中配置预算、身份、保留期限和容量 |
| SupervisorErrorHandler | 修改，处理 401/403/404/409/413/429/503 等边界 |
| RequestGate | 删除；执行许可由持久任务所有者管理，不能跟随 HTTP 断开释放 |
| SupervisorDemo | 修改，使用同一核心和显式本地身份，关闭自有模型传输 |
| SupervisorApplication | 复核，继续只扫描当前包；启动配置校验由容器完成 |

## 明确不作出的保证

- 此 Demo 不是 Claude Code 或 Codex 的一比一移植。
- H2 本地恢复不是多实例执行租约；`toolCallId` 不是业务幂等键。
- 准确字段和原文摘录可以核对，任意自然语言结论不能据此自动证明正确。
- 使用示例天气、车次、资料；没有真实票务写入，没有把单测当真实模型效果验证。
