## 结论

此前两处剩余 P1 权限来源缺口已在当前代码中闭合，本次限定范围未发现新的明确 P1/P2 阻断项。

- **HTTP 会话历史来源链**：`ConversationService.enrichWithPermissions` 在同一次读取中返回实际可见回答及其权限；`TaskStoreService.newTask` 保存到 `agent:inherited-permissions`，`LoopConversation` 在加载文本前恢复并检查。完成时 `saveConversation` 将历史权限传给 `ConversationService.complete`，与本轮证据权限合并保存。撤权后的新请求隐藏原回答及仅引用原回答的衍生回答，隐藏内容不再向新上下文增加权限。对应回归：`AgentLifecycleTest.serverConversationPermissionsSurviveAnswerReuseAcrossHttpTasks`。
- **旧 Agent 回执和消息**：`AgentSnapshotDTO`、`AgentMessageDTO` 的紧凑构造器将显式权限与 `result.evidence` 来源合并，兼容缺失新字段的旧持久 JSON。`ChildAgentDispatcher` 和 `Supervisor.receiveMailbox` 将来源累积到调用者历史，再随检查点保存；即时校验和后续恢复均有来源可查。对应回归：`AgentLifecycleTest.legacyAgentPayloadsDeriveMissingPermissionsFromResultEvidence`。
- **跨回合权限**：历史来源独立于本轮证据，经过新轮、摘要、fork、完成通知与 HTTP 结果重放仍保留。已检查 `RunContext`、`LoopConversation`、`AgentLifecycle`、`TaskService` 和 `TaskStoreService` 的对应入口。
- **CLI 并发上限**：闲置子会话 followup 在持树锁时、写入邮箱及启动前校验活动子会话数；满额拒绝不改变邮箱和状态。对应回归：`AgentLifecycleTest.localFollowupRejectsFullChildCapacityBeforeEnqueue`。
- **预算耗尽等待**：本地及持久实现先观察新输入/邮箱，再在本子树无活动后代且树调用额度耗尽或后代已经预算失败时结束等待。后代因分钟额度失败也会留下 `BUDGET_EXHAUSTED`，无须只依赖树调用计数。相关共享预算等待回归已存在。
