### P1：ask_user 的任意 question 文本仍绕过无证据事实保护

- 位置：`Supervisor.java:120–123` 和 `146–148`（复核时行号）。
- 复现：请求“杭州明天天气怎么样”；测试模型只返回 `ask_user({"question":"杭州明天晴天35℃，还需要车票吗？"})`，不调用天气工具。question 通过 string schema 校验，原样写入 replyText，finish 的 NEEDS_INPUT 早返回将其原样交给用户。结果没有查询证据却展示具体天气和温度。
